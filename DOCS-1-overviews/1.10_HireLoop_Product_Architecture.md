# HireLoop Product Architecture

## System Overview

HireLoop is a comprehensive AI-powered interview orchestration platform that automates technical hiring through intelligent question generation, real-time proctoring, and agent-based coordination.

## Core Components

### 1. Frontend Layer (React/Next.js)
- **Component Architecture**: Atomic design system with Tailwind CSS
- **State Management**: Client-side state with Zustand and Context API
- **Real-time Communication**: WebSocket hooks for instant updates
- **Routing**: Next.js with protected routes for interview flows
- **Responsive Design**: Mobile-first approach with adaptive layouts
- **Accessibility**: WCAG 2.1 AA compliance with ARIA integration

### 2. Backend Layer (FastAPI/Python)
- **API Design**: RESTful API design with OpenAPI documentation
- **Authentication**: JWT-based auth with session management
- **Real-time Engine**: WebSocket relay for audio/video streams
- **Database**: Supabase with PostgREST for API-first data access
- **Middlewares**: Rate limiting, CORS, request logging
- **Testing**: Comprehensive test coverage with pytest

### 3. AI Integration Layer
- **Question Generation**: Gemini API for role-specific interview questions
- **Scoring Engine**: Gemini-based evaluation with custom scoring rules
- **Proctoring**: Computer vision + audio analysis for cheating detection
- **Agent Coordination**: Claude Code + Codex for intelligent workflow management
- **Adaptive Logic**: Dynamic question difficulty adjustment

### 4. Infrastructure & Operations
- **Cloud Storage**: Supabase for all persistent data
- **CDN**: Static asset delivery optimization
- **Monitoring**: Application performance monitoring
- **Logging**: Centralized structured logging
- **Scaling**: Horizontal scaling with load balancing

## Security Architecture

### Authentication & Authorization
```python
# Middleware example
@app.middleware("http")
async def auth_middleware(request: Request, call_next: Callable):
    # Token validation
    token = request.headers.get("authorization")
    if token:
        payload = verify_token(token)
        request.state.user_id = payload.user_id
        request.state.roles = payload.roles
    
    response = await call_next(request)
    return response
```

openapi: 3.0.0
info:
  title: HireLoop API
  version: 1.0.0

  - url: https://api.hireloop.com
    description: Production server
  - url: https://staging-api.hireloop.com

      requestBody:
        required: true
        content:
          application/json:

          description: Interview created successfully

              schema:

      type: object

          type: string
        job_role_id:
          type: string

          format: date-time

          type: string
