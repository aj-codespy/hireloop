# HireLoop Platform Overview

## What is HireLoop?

HireLoop is an **AI-powered interview orchestration platform** designed to streamline the technical hiring process. It leverages generative AI (Gemini) for intelligent interview question generation, proctoring AI, and comprehensive candidate evaluation—all while maintaining the human touch in hiring.

### Core Mission

**To democratize technical hiring by eliminating interview bottlenecks through AI automation while ensuring fairness and quality in every assessment.**

## Product Highlights

### 🚀 Key Features

1. **Intelligent Question Generation**
   - Role-specific interview questions powered by Gemini AI
   - Custom scoring rules and evaluation metrics
   - Adaptive question difficulty based on candidate performance

2. **Proctored Video Interviews**
   - Real-time AI proctoring with facial recognition
   - Audio proctoring for cheating detection
   - Automated session analysis and reporting

3. **Automated Interview Orchestration**
   - Smart scheduling with AI agent coordination
   - Multi-agent collaboration (Claude Code + Codex workflow)
   - Seamless integration with existing hiring tools

4. **Comprehensive Analytics**
   - Real-time interview tracking
   - Performance metrics and reports
   - AI-driven insights for better hiring decisions

## Technology Architecture

### Frontend (React/Next.js)
- Component-based UI with Tailwind CSS
- Real-time WebSocket communication
- Responsive design for all devices
- State management with Zustand

### Backend (FastAPI/Python)
- Asynchronous API design
- Supabase for persistent storage
- Gemini AI integration for scoring
- WebSocket relay for audio/video streams

### AI Integration
- **Gemini** for question generation and scoring
- **Claude Code & Codex** for agent coordination
- **Supabase** for data persistence
- **Real-time communication** via WebSockets
