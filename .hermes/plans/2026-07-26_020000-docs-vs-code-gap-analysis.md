## What HireLoop Is (Product Identity from Docs)

From `DOCS-1-overviews/1.1_HireLoop_Platform_Overview.md`, `brand-guidelines.md`, `design.md`, and `DOCS-1-overviews/1.10_HireLoop_Product_Architecture.md`:

### Core Mission
> "To democratize technical hiring by eliminating interview bottlenecks through AI automation while ensuring fairness and quality in every assessment."

### Product Tagline
> "Structured interviews. Reviewable evidence. Defensible decisions."
> "HireLoop owns the interview. You own the offer."

### Key Features (Doc-Claimed)
1. **Intelligent Question Generation** — Gemini AI generates role-specific questions
2. **Proctored Video Interviews** — Real-time AI proctoring with facial recognition + audio analysis
3. **Automated Interview Orchestration** — Smart scheduling, multi-agent collaboration
4. **Comprehensive Analytics** — Real-time tracking, performance metrics, AI-driven insights
5. **AI Scoring Engine** — Gemini-based evaluation with custom scoring rules
6. **Agent Coordination** — Claude Code + Codex for intelligent workflow
7. **Webhook Integration** — `candidate.qualified` fires on completion

### Brand Personality
> Calm, Trustworthy, Intelligent, Human. "Stripe meets Linear meets Apple." Rust orange primary (#F97316), 90% white / 8% gray / 2% orange ratio. Geist typography. Phosphor icons (1.5px stroke). Generous whitespace (60% spacing, 40% content).

### Target Audience
> Tech startups, Enterprise, Freelance platforms, Ed-tech. Purchasing-power devs in US, Europe, Brazil, Canada.

### System Boundary
> HireLoop owns AI screening + human orchestration → qualified candidate list → `candidate.qualified` webhook. Customer owns offer/onboarding/background-check/HRIS.
